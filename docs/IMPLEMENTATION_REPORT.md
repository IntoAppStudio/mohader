1. طبّق الهجرتين: `supabase db push` (ملفا `20261030090000_*` و`20261030091000_*`).
2. أعد توليد الأنواع: `supabase gen types typescript` (الكود الجديد يستخدم `untypedDb.server.ts` مؤقتاً لحين ذلك).
3. أضف متغيرات `.env.example` الجديدة (`APP_BASE_URL`، `CRON_SECRET`، `EMBEDDINGS_*`، `MOYASAR_*`…).
4. جدول كرون (كل دقيقة): `POST /api/cron/run-queue` — يومياً: `POST /api/cron/purge-expired-files` (كلاهما بـ `Authorization: Bearer $CRON_SECRET`).
5. فعّل الأعلام تدريجياً من جدول `feature_flags`: `queue_processing`، `credits_enforced`، `server_tts`، `whiteboard`، `audio_lessons`، `video_lessons`.
6. `npm install && npm run ci`.

## ما لم يُتحقق منه (صراحةً)
- بيئة العمل بلا شبكة: لم يُشغَّل `npm install` ولا `build` ولا `lint` ولا المتصفح. فُحصت الأنواع جزئياً بتعريفات مؤقتة، وشُغّلت الاختبارات النقية فقط. **شغّل `npm run ci` أولاً.**
- `WhiteboardPlayer` لم يُجرَّب في المتصفح (تشغيل، تقديم/تأخير، ملء الشاشة، العربية).
- مسارات `routeTree.gen.ts` تُولَّد تلقائياً عند أول `dev/build` للمسارات الجديدة.
- واجهات مستخدم غير مبنية: صفحات خريطة الضعف، العد التنازلي، امتحان الدكتور، المعلم/الطالب، متجر الباقات (الدوال الخادمية جاهزة).
- طابور Supabase/Inngest/Trigger.dev لم يُستخدم؛ استُخدم طابور على Postgres (لا اعتماد خارجي) ويمكن استبداله لاحقاً.

## تحديث الإصلاحات (الجولة الثانية)
- صفحة الدورة: عند تفعيل علم `queue_processing` يمر البناء ومعالجة الملفات عبر الطابور مع شريط تقدم حي وتقدير التكلفة قبل البدء؛ وعند تعطيله يعمل المسار القديم كما هو.
- ثغرة الباقات: نقاط الباقة تُمنح مرة واحدة في `credit_wallets.bonus_credits` بتاريخ انتهاء، ولا تُعاد كل شهر (`grant_pack_credits` + webhook مع منع التكرار).
- `ai_cache`: مفتاحه مرتبط بالمستخدم، ويُحذف بعد 30 يوماً من الكرون اليومي. وأُضيف backfill لتواريخ حذف الملفات الحالية.
- إصلاح: كتلة نصية واحدة ضخمة لم تعد تُهمل بصمت في حلقة البناء.
- شاشة مراجعة العناصر المحجوزة: `/courses/$courseId/review` (اعتماد/حذف).
- رابط الصوت الموقّع صار ساعة بدل 5 دقائق؛ وتوحيد فئة `TtsUnavailableError`.
